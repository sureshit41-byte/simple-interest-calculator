# Simple Interest Calculator

## Project Name
Simple Interest Calculator

## Description
This project is a Bash-based simple interest calculator.
It accepts the principal amount, rate of interest, and time period
from the user and calculates the simple interest.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

- Bash
- Git
- GitHub
